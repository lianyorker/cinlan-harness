# Cinlan 设置架构

[English](cinlan-feature-navigation.md) | 中文

## 概述

Cinlan 采用包含七个产品分组的单页全屏设置。本文档作为导航规则与设计理由的事实源。外壳负责分组、搜索、焦点、响应式导航及当前选中分区；功能包负责各自控件、持久化、能力状态及本地化元数据。Profile 装配保持相同的包与命名空间契约，因此 Profile 省略某项能力时不会产生无效页面。

## 安全与执行前提

RPC 调用方是已认证本机用户，非多租户客户端。Remote 端点信任由 Session 和 Host 启动过程建立的本机回环边界。安全研发、终端执行和进程编排在调用用户的操作系统权限下运行，不引入内部权限隔离边界。

## 导航分组

| 分组 | 分区职责 |
|---|---|
| 个人 | 常规、语音、浮动工作区、账号、快捷键 |
| 智能体 | 模型、智能体预设、Agent 循环、子智能体 |
| 工作区 | 终端、Git、工作树（待落地）、工作区隔离、任务源、文件 |
| 执行与安全 | 权限与审批、执行宿主 |
| 工具与设备 | 浏览器、电脑操控、移动设备（待落地）、安全研发、桌面手机配对（可选，待落地） |
| 连接与扩展 | 集成、MCP、联网搜索、未来技能（待落地） |
| 数据与高级 | 使用统计、归档会话、运行时诊断、插件与 Bundle |

七个分组 id 为 personal、ai、workspace、execution、tools、extensions 和 advanced。分区 id、设置命名空间、保存／重置操作和 Remote 方法名仍归属各功能包。功能在单一 effect 生命周期内注册分区及其可搜索字段；功能释放时同时移除两项贡献。

## 外壳行为

ui-settings-general 在应用根节点旁渲染全屏路由。导航栏与内容列独立滚动，窄窗口将导航栏移入抽屉。搜索对本地化公开标签、描述、关键词和稳定锚点建立索引，绝不读取设置值或敏感信息。选择搜索结果会打开所属分区，按需激活对应标签页并聚焦已注册锚点。

分区元数据声明顶层标题归属。外壳为紧凑的历史页面补充标题；功能拥有的页面保留自身标题层级，因此新增页面无需在外壳维护分区 id 清单。

ui-settings 保持设置数据与元数据底座定位。它提供共享设置镜像、Schema 操作、分区 slot、条目元数据及启动器契约。外壳不复制功能表单、不推断 Host 能力，也不维护集中式路由表。

## 功能归属

模型与智能体预设归入智能体组，保留既有 Remote 和持久设置所有者。权限、Shell、agent-loop、subagent 和 web-search 页面直接作为顶层分区注册在各自产品组；历史 plugins.item 注册与兜底联合类型已彻底退役。运行时设置属于数据与高级顶层分区；插件条目仅对仍暴露该能力的部署保留兼容启动器。

快捷键只有唯一入口。其个人分区内联渲染窗口内快捷键速查，Mod+/ 弹层打开同一份组件，因此两个入口列出相同的应用命令与固定输入操作。通用设置不再贡献快捷键行；通过键盘服务注册的命令在该速查的“其他操作”分组中展示。

任务自动化与计划调度解耦为两个包。automation Host 保留无人值守执行与预设驱动调度，但不挂载任何客户端 UI，因此官方的计划调度包是唯一的自动化界面：其任务管理器面板、任务详情与会话任务卡片。设置在执行与安全下提供自动化组合包的开关，官方计划调度包继续提供任务管理器面板、任务详情与会话任务卡片。

能力页面遵循严格的双层守卫模型：
1. 存在守卫：由 Bundle 挂载驱动。若某能力的 Bundle 未在当前 Profile 中挂载，其 UI 分区将完全从设置导航中排除。
2. 就绪守卫：由运行时环境检测驱动。当 Bundle 已挂载但缺少 Host 前置条件（如 ADB、录屏权限）时，页面渲染诊断引导而非损坏的控件。

可选的手机配对页面额外要求 dsh-app: 桌面载体及回环 Host；默认 Web/CLH 组合不挂载其配对控制器或设置行。Web bundle 通过 cordis.patch.yml 挂载 Remote 装配及可选的语音、安全、Git 和侧栏提供者；clh 保持相同行列与 Profile 特异性启用。

## 装配与验证

packages/api/remotes 将所选生成的 Host Remote 挂载且仅挂载一次，包括工作区隔离、工作树任务、设备能力、安全研发、工作项、浏览器、集成、用量、语音、MCP、执行宿主及侧栏 Git／终端服务。手机配对保持在此默认装配之外；显式 Profile 须将配对控制器与 Client 页面共同装配。

聚焦的 UI 测试覆盖元数据分组、全屏导航、搜索目标、运行时分区及计划任务管理。Remote 装配由 Client 类型图与生成的契约构建检验。全应用测试仍依赖现有浏览器与外部服务夹具。
