## 数据处理

根据当前任务的数据处理与发布要求决定是否脱敏。需要生成可分享版本时，使用以下本地占位符：

- 目标域名/IP：`{target_domain}` / `{target_ip}`
- 真实 URL 路径：保留结构并替换域名
- Token/Cookie/密码/JWT/API key：`{token}` / `{password}` / `{api_key}`
- 用户名/手机号/邮箱：`{username}` / `{phone}` / `{user_email}`
- 内部 IP/端口：按任务要求保留或替换，例如 `10.0.x.x`
- 漏洞 payload：保留技术内容并按需要替换目标特征参数，例如 `?id={user_id}`

发布前搜索 token、cookie、password、api key、邮箱、手机号、真实域名和目标 IP，并人工复核命中项。该模板不依赖外部案例索引或脱敏脚本。
