# @deepseek-ai/dsh-mcp-management

[English](README.md) | 中文

## 概述

MCP（模型上下文协议）管理服务为当前配置档持久化服务器定义，并通过现有 [MCP 客户端桥接器](../mcp-client/README.zh.md)运行它们。保存的启用状态与观测到的就绪状态相互独立：凭据缺失或端点不可用时，启用记录会被保留，并报告实际激活错误。

<a id="configure-management"></a>
## 配置管理服务

挂载桥接器注册表、storage-domain 组件、凭据、工具和本服务。必填的 `profile` 配置是应用程序的真实配置档身份。定义保存在版本 1 的 `mcp_management` 存储域中，位于 `profiles` 表。它们不会改写组合 YAML 或整个 Harness 主目录共享的设置文档。

stdio 定义包含可执行程序、字面量参数、工作目录，以及环境变量到凭据引用的映射。Streamable HTTP 定义包含端点和请求头引用，每条引用带有 `Bearer ` 等非机密前缀。URL 不允许用户信息、查询字符串和片段。认证值属于[凭据提供方](../../credentials/credentials/README.zh.md)，不得放在参数或字面量请求头字段中。省略的时间选项使用桥接器现有的超时与重连默认值；无效覆盖在持久化之前被拒绝。

<a id="manage-servers"></a>
## 管理服务器

[公开请求与快照类型](src/types.ts)将持久化记录 id 与工具命名空间分开。保存、移除和启用状态变更会比较当前配置档版本与调用方的预期版本。过期编辑器会收到冲突。连接错误不会增加该版本。

保存先提交期望定义，再应用它。重连只替换已启用且由管理服务拥有的子插件，并重新解析凭据引用。自动重连也会在每次尝试时重新解析。禁用会停止该子插件。移除先停止它，再提交删除。无法确认关闭时会报告固定错误并保留记录；无法证明该生命周期已经关闭时，替换会被拒绝。

刷新工具使用已初始化连接的串行 `tools/list` 路径。它不会启动已停止的服务器，也不会调用 `tools/call`。仍保持连接的错误状态可以通过成功发现工具恢复；已断开的服务器需要启用或重连。外部组合的根连接显示其真实 Loader 条目或插件拥有者，并保持只读。Agent 作用域连接根据上下文携带的作用域身份排除。

<a id="lifetime-and-persistence"></a>
## 生命周期与持久化

服务拥有的单个操作队列串行执行版本检查和持久化写入。权威域记录仅在持久化成功后发布。观测到的连接阶段和工具描述来自桥接器监督器，没有第二个传输客户端，也不独立重建就绪状态。观察注册表并不授予对外部 Loader 条目的变更权限。

管理服务卸载时会先停止子插件并排空写入，再关闭存储域。其 `./invariant` 伴随插件在工具执行前比较已完成应用的期望记录与独立注册的根连接；桥接器拥有另一项发现结果与工具注册关系的不变量。管理服务的公开快照和错误不包含解析后的凭据或上游异常文本。

<a id="model-experience"></a>
## 模型体验

间接影响，经由 MCP 客户端桥接器贡献受管服务器发现的工具。

#### KV Cache 影响

更改连接发现的工具 schema 可能改变模型的工具前缀。管理服务不创建提供方请求，也不独立修改 Session 日志；常规工具运行时记录调用与结果。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

管理范围仅涵盖当前配置档的根连接。外部组合和 Agent 作用域服务器保留自己的生命周期权限。认证使用静态环境变量或请求头引用；不支持 OAuth。参数和端点路径是公开配置，不得包含秘密。无法确认传输关闭时，需要恢复 Host 后才能复用被隔离的命名空间。
