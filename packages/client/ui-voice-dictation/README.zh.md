# @cinlan/client-ui-voice-dictation

[English](README.md) | 中文

## 摘要

在语音设置中选择麦克风、听写模式和首选语音模型。在所连接的主机上安装、重新安装、更新或删除模型资源，检查引擎状态，并测试麦克风采集与转写。听写会把识别结果插入录音开始时获得焦点的文本表面；受管输入区仍写入发起会话的草稿，供用户检查后再发送。偏好保存在浏览器中；音频处理和模型资源属于主机。

## 使用本包

在设置中打开「语音」。Web 与 Desktop profile 内置听写，无需可选语音插件。禁用听写时，可搜索的字段仍然可见，依赖控件保持禁用。启用听写且主机上有就绪模型时，输入区显示麦克风按钮。录音开始、录音中和转写期间，应用 frame 还会显示独立状态条；它跨会话导航保留，转写期间停止操作不可用。此浏览器插件没有插件配置字段。

### 偏好与资源

| 控件 | 存储或权威来源 | 消费者与效果 |
|---|---|---|
| 启用语音听写 | 浏览器 `dsh.voice.settings.enabled` | 启用时，输入区按钮与快捷键接受新的听写操作。 |
| 听写模式 | 浏览器 `dsh.voice.settings.dictationMode` | 设置页显示 Ctrl+Shift+E 快捷键。切换模式用它开始/停止；按住模式在松开 E、修饰键或窗口失焦时停止。按钮始终以切换方式工作。 |
| 终端插入前确认 | 浏览器 `dsh.voice.settings.terminalConfirmBeforeInsert` | 默认关闭。启用后，捕获目标为终端时会在插入完整转写前询问；拒绝后终端内容不变。其他文本目标不受影响。 |
| 输入设备 | 浏览器 `dsh.voice.settings.microphoneDeviceId` | 下一次录音把所选设备传给 `getUserMedia`；设备缺失或不再满足精确设备约束时，本次录音改用系统默认设备并显示提示，不修改已保存偏好。「系统默认」会清除设备偏好。 |
| 麦克风权限 | 浏览器/操作系统；同源本地回退 | 请求权限后释放临时音轨并刷新设备名称。Permissions API 的真实 prompt 状态会清除过期授权；不支持查询时使用最后一次权限决定。 |
| 语音模型 | 浏览器 `dsh.voice.settings.sttModel` | 转写使用所选的就绪模型，否则使用首个就绪模型；「自动」清除偏好。 |
| 语言 | 浏览器 `dsh.voice.settings.language` | `auto`、中文、英语、日语或韩语会转发给 OpenAI、Whisper 和 SenseVoice；其他本地模型使用目录语言。 |
| OpenAI API Key | Host 凭据 | 设置页在不暴露密钥的情况下保存、轮换、查询和清除 `OPENAI_API_KEY`；配置凭据后云端模型才就绪。 |
| 引擎与模型资源 | 所连接的主机 | 安装、重新安装、更新、精确任务取消和删除通过 Web 与桌面通道调用生成的 `voice` Remote。删除需要页内确认。操作失败时显示本地化恢复指引。 |
| 麦克风测试 | 页面生命周期 | 显式点击后使用所选设备采集最多十秒音频，显示输入音量，并把有界 PCM 发送给所选就绪模型。转写结果只保留在此页。 |

浏览器偏好写入后立即生效。已保存但不可用的麦克风保持选中。精确设备采集返回 `NotFoundError` 或 `OverconstrainedError` 时，本次录音仅重试一次系统默认设备，并在发起会话中提示回退；权限拒绝和其他采集失败不会触发回退。该偏好不会复制到主机设置。拒绝权限不会清除偏好。存储拒绝写入时，当前设置仍可使用，但改动无法在重新加载后保留。

语音模型菜单包含模型选择和资源操作，显示本地化说明、语言范围、识别类别与体积。只有就绪模型可选；下载不改变模型偏好。展开「模型详情」可查看来源 URL、完整性、已安装和可用清单指纹。版本标识固定清单，不代表上游发行版；「检查模型版本」刷新主机目录状态。仅当主机报告可用更新时启用「更新」。替换任务运行时模型可保持就绪；取消只针对该确切任务，不删除已安装模型。离开设置不会取消主机安装任务。引擎降级时提供可复制的修复命令。首次查询失败时提供「重试」；后续查询失败时保留最后报告的资源行。

页面可导入含有 `clh-voice-model.json` 的 Host 目录；Host 校验后将模型复制到受管存储，原目录保持不变。OpenAI 云端模型使用 Host 凭据，不会暴露本地缓存目录。

主机报告引擎和模型就绪前，麦克风测试保持禁用。停止时先释放麦克风音轨再转写；取消、禁用听写以及离开页面均会释放采集并抑制延迟结果。取消后才完成的权限请求也会释放其音轨。音频不会保存，测试不会修改或发送会话草稿。空转写、采集失败和主机失败均显示本地化指引。

### 听写与草稿

快捷键忽略可编辑字段、重复按键、输入法组合事件，以及已被其他功能处理的事件。即使用户切换到其他会话，录音和插入仍属于发起会话。在 E 之前松开修饰键也能停止按住听写。

麦克风访问前会解析所选就绪模型。在线模型通过已认证的 `voice` Remote，以有界 100 ms 分块发送持续重采样后的 PCM；应用状态条显示 partial 假设，但只有收到完整 final 文本后才会插入。流被取消或失败时会丢弃 partial 文本。离线模型仍保留完整录音，并调用现有 unary 转写。停止时先关闭采集并释放麦克风音轨，再结束 uplink 或等待转写。麦克风请求前会捕获插入目标：input 和 textarea 在原选择位置插入文本，`contentEditable` 表面在原 Range 插入文本，侧栏终端接收本地插入事件。终端确认默认关闭，且只作用于捕获的终端目标。受管输入区仍追加到最新草稿，并保留转写期间的编辑。保留原有空白；相邻非 CJK 字母或数字之间，以及拉丁标点后接词语时添加分隔空格；中日韩文字边缘、括号和闭合标点处不额外加空格。空转写不修改目标；权限、采集、缺少模型或主机错误均保留草稿，并在输入区发布错误提示。听写不会发送草稿。

## 了解实现

<details>
<summary>实现内部细节 — 点击展开</summary>

[apply.ts](src/client/apply.ts) 在设置、快捷键、输入区按钮和应用级状态条之间共享一个浏览器本地偏好 store 和听写控制器，并以普通回调提供主机操作。页面分组、公共元数据描述与 slot 贡献共享同一次声明生命周期，拆除时一起移除。元数据只包含本地化标签、说明和关键词，不包含偏好值、设备标识、模型路径或转写文本。稳定锚点始终挂载，搜索导航不会顺带启用听写。

[VoiceSettingsSection.tsx](src/client/VoiceSettingsSection.tsx) 负责权限请求和设备枚举、消费主机资源状态，并在设置壳层提供的内容宽度内渲染原生风格设置行。[dictation-controller.ts](src/client/dictation-controller.ts) 在访问麦克风前解析就绪模型，发送在线 PCM uplink，并只将 final 文本路由到捕获的插入目标或会话输入 API。[dictation.ts](src/client/dictation.ts) 持续重采样 AudioWorklet 帧，并合并为有界分块。[insertion-target.ts](src/client/insertion-target.ts) 负责恢复选择并为受控文本表面派发 `input` 事件。插件拆除会使结果发布失效、中止等待中的 Remote 调用、关闭活动采集，并等待自身异步操作结算后返回。

[包测试](tests/) 覆盖元数据生命周期与语言切换、重新挂载后的偏好、麦克风与设备结果、主机资源操作，以及听写草稿保留。

</details>

<a id="model-experience"></a>
## 模型体验

### 只写入草稿的听写

#### 模型看到什么

用户发送草稿之前，模型看不到任何内容。提交后文本作为 `user` 消息遵循普通输入流程；此包不提供提示词、schema 或工具。

#### Token 影响

设置、录音和转写本身不增加 token。发送的草稿文本按普通用户消息消耗 token。

#### KV Cache 影响

语音偏好、权限与模型资源没有影响；这些信息不会进入模型请求前缀。

## 已知限制与暂缓事项
<a id="known-limitations-and-deferred-work"></a>

不发布 invariant companion：slot、locale 和快捷键注册均使用其所有者管理的 effect，听写 UI 不保留这些注册的独立副本。

语音依赖浏览器采集与可访问的主机 Provider。

- Web 与 Desktop 共用生成的 `voice` Remote。引擎是否就绪仍取决于本地 sherpa-onnx 原生模块与模型文件；页面显示降级状态和修复指引。
- 浏览器麦克风权限与设备标识不在设备或 origin 之间同步。存储的权限回退不能授予浏览器或操作系统访问权限。
- 采集使用内嵌 `AudioWorkletNode` 处理器，并将收到的音频帧线性重采样至 16 kHz。Chromium 浏览器测试已验证 Blob 模块加载，以及其 fake microphone 提供非零音频帧。这不能证明物理设备的输入振幅或模型准确度；两者仍需分别验收。
- Streaming 模型在录音期间提供 partial 假设。离线模型仍累积完整录音，并在停止后转写；目前没有独立的启动缓冲。
- 听写期间麦克风音轨结束时，客户端会关闭采集、丢弃不完整音频，并向发起会话显示错误。后续尝试会重新尝试已保存设备；精确设备不可用时会提示并临时回退到系统默认设备。
- 自动标点仍暂缓。
