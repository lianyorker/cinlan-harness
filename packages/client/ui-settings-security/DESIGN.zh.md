# 能力设置设计参考

[English](DESIGN.md) | 中文

## 范围

本参考覆盖 Cinlan Settings 贡献，不改变 Settings 外壳或插件注册表。用户参考图定义克制的中性设置页：能力身份与真实状态优先，其次是已支持的后续操作，最后是组件诊断。

## 布局

- 内容列最大宽度为 840px；所有能力标题共享左对齐线。
- 页头使用 22px/30px 字体与细底线；正文使用 14px/22px。
- 主卡片内边距 20px、圆角 10px、图标 44px，状态同时显示文字。
- 计算机控制、安全研究与设计使用间距 12px 的双列说明卡片；640px 以下改为单列。
- 浏览器使用三个有序设置步骤。手机模拟器区分可用性、SDK/默认设备说明与 Agent 控制设置。
- 复制与重新检查控件至少 40px；焦点外框为 2px，偏移 2px。

## 主题与状态

所有颜色使用[样式表](src/client/CapabilitySection.module.css)中的既有语义主题别名。状态文字使用可读的中性色，彩色圆点只作辅助。未配置显示中性状态，真实失败同时显示错误文字与状态标签。组件不声明静态调色板或独立明暗主题。

Loader 激活、Provider 可达、安装与授权是不同事实。尚不支持的 SDK 与安装操作显示为说明。Browser Cookie 与文件控件必须由用户显式操作，仅展示 Host 确认的结果。原始 Loader 详情默认收起。

## 侧栏关系

独立安装的工作面板默认收起。Session 页头工具可见时，收起的控件与标题行对齐；打开右侧面板后，控件移入其标签栏。减少动态效果时取消过渡。真实浏览器场景检查 1680px、1000px、600px 宽度，并包含移除偏移的反例对照。

浏览器启动偏好使用第一步设置行中的原生带标签控件。保存结果区分持久化与实际生效，并保留失败草稿；偏好控件不会启动浏览器。显式导航与文件操作放在偏好表单之后，使用原生带标签控件，状态与部署配置分开。

安全范围与报告控件使用原生标签、40px 操作区域、既有语义边框和明确的保存/错误状态。失败草稿保持可见；读取 Settings 不生成报告。网络出口与凭证引用使用独立标签行组、纵向字段和显式添加/删除按钮。新行不预填协议、用途或目标；凭证说明区分引用名称与秘密值。

## 验证

[Web 场景](../../../apps/web/tests/device-capabilities.e2e.ts)负责 ARIA 预期、窄内容列溢出与侧栏几何。[安全研究覆盖](../../../apps/web/tests/security-capabilities.e2e.ts)加载实际可选组合包并撤回其预设贡献。原生 Orca 输入与第三方安装器不属于本轮视觉验证。
