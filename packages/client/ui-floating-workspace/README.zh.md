# @deepseek-ai/dsh-client-ui-floating-workspace

[English](README.md) | 中文

## 概要

浮动工作区在独立窗口中打开现有应用，同时保留主窗口。设置控制入口位置以及下一个窗口请求的尺寸。安装实际终端消费者后，新建浮动终端也会使用保存的目录；缺少消费者时，该字段明确显示为不可用。

<a id="use-this-package"></a>
## 使用此包

打开设置 → 个人 → 浮动工作区并启用功能。启用只增加入口，不会打开窗口。通过该入口、设置页的打开操作或已注册的快捷键，可打开和关闭一个工作区窗口。关闭功能会关闭它拥有的窗口。现有偏好通过常规的带版本设置写入器，保存在 Host 的 `floating-workspace` 命名空间中。

| 偏好 | 默认值 | 生效方式 |
| --- | --- | --- |
| 启用浮动工作区 | 关闭 | 显示入口并启用命令；禁用时关闭拥有的窗口。 |
| 入口位置 | 会话头部 | 选择会话头部、侧边栏底部或浮动按钮。 |
| 窗口宽度 | 400 像素 | 下次打开时请求 200–800 之间的整数像素。 |
| 窗口高度 | 300 像素 | 下次打开时请求 150–600 之间的整数像素。 |
| 终端启动目录 | 空 | 为空时，新浮动终端继承关联会话的目录；配置的现有目录必须解析为该目录或其子目录。 |

仅存在会话头部时才显示头部入口。在应用的无会话视图中，也可以使用设置页的打开操作和快捷键。默认命令为 Ctrl + Shift + Space；键盘快捷键页负责覆盖值与冲突提示。尺寸变更只作用于之后打开的窗口。浏览器和操作系统可能限制实际尺寸。

子窗口加载相同的应用产物，以及正常的布局、会话、工作区和终端插槽。在展开和紧凑布局中，“关闭工作区窗口”控件都位于侧边栏底部。如果来源会话在已接受的目录中，子窗口首先选择该会话，随后保留正常导航。会话缺失时，子窗口提示可选择其他会话。仅打开窗口不会创建会话或提交对话输入。

只有实际终端渲染器提供消费标记时才能编辑目录。每个新浮动 UI 终端捕获窗口身份与已接受的目录。终端 Host 在启动前验证现有目录的包含关系，包括符号链接。运行中的终端，以及主窗口或 Agent 终端的目录均不受影响。偏好仍在加载或不可用时，新的终端尚未就绪，但保留用于隔离布局的浮动窗口身份。

Web 弹出窗口被阻止时，会在页头下方显示明确的重试提示，配置的入口仍可用于重试。不支持的环境或被拒绝的原生应用窗口请求会显示不可用。关闭时，如果来源窗口仍存活，则将焦点还给仍连接到文档的原始控件。打开状态不会持久化，也不会自动恢复窗口。

### 组合与配置

Host 入口注册现有的五字段 schema。Client 消费设置、语言、插槽、键盘和会话服务；设置页使用 `floating-workspace` 分区标识和 `personal` 分组。可选的 `floatingTerminalConsumer` 服务只在真实终端消费者的生命周期内允许编辑目录。共享的 `floatingWorkspaceContext` 回调发布 [侧边终端类型](../../terminal/sidebar-terminals/src/types.ts) 中的 JSON 数据；不会跨包导入 UI 实现。

| 部署配置 | 默认值 | 含义 |
| --- | --- | --- |
| `windowClosedPollMs` | 500 | 检查确切拥有的 WindowProxy 是否被外部关闭，范围为 100–5000 毫秒；仅在拥有窗口时创建定时器。 |

<a id="understand-the-implementation"></a>
## 了解实现

<details>
<summary>实现细节 — 点击展开</summary>

[注册入口](src/client/index.ts) 拥有词典、可搜索元数据、命令，以及现有设置、头部、侧边栏和浮层插槽中的贡献。设置元数据跟随设置插槽声明的生命周期。组件接收框架绑定的可观察事实与普通回调。浮层将键盘匹配交给键盘服务，且不会在子窗口中安装命令监听器。

[运行时](src/client/runtime.ts) 保留一个确切的窗口句柄与已接受的设置快照。写入使用规范的设置变更操作，并同时确认生效字段和原始已接受字段。写入被拒绝时保留已接受值。禁用、页面退出和销毁会关闭拥有的子窗口；销毁还会移除观察并等待进行中的偏好写入。经过验证的子窗口在设置就绪前就暴露窗口身份，因此终端消费者可以在创建布局状态前选择隔离存储。

[浏览器适配器](src/client/window-environment.ts) 在用户操作中同步打开窗口。URL 只包含浮动标记、经过验证的窗口 UUID，以及可选的非秘密会话标识。凭据、无关查询参数和片段标识均被移除。它使用正常的应用来源和认证载体。[Desktop 策略](../../../apps/desktop/src/floating-window.ts) 只允许主应用发起确切的 `dsh-app://app/index.html` 浮动路由，固定可信 preload 与安全选项，拒绝子窗口弹出和其他导航，并在来源窗口或 Host 替换时销毁确切拥有的子窗口。

本包不发布运行时不变量配套入口：已接受的设置和窗口句柄具有单一所有者，外部关闭是被观察的生命周期事件，而不是另一份权威注册表。Loader 持久化测试、注册销毁测试和窗口生命周期测试覆盖这些关系。

</details>

## 模型体验

无，因为本包不注册面向模型的提示或工具，也不写入会话事件。

#### KV 缓存影响

无；本包不会组装或发送提供商请求。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

运行环境控制弹出窗口可用性和最终窗口尺寸。缺少所需 UUID 能力的浏览器会显示功能不可用。无会话视图没有会话头部插槽位置。缺少真实终端消费者时，目录字段保持禁用；终端 Host 会拒绝所选会话工作树以外的目录。本包不提供目录选择器、终端实现、自动窗口恢复或独立应用外壳。
