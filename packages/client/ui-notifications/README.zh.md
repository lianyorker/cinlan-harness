# @deepseek-ai/dsh-client-ui-notifications

[English](README.md) | 中文

## 概述

选择 agent（智能体）完成提醒和新工具结果中响铃字符的桌面通知。在可写的回环主机上，通知偏好会持久保存。专注静默和每日免打扰时段会抑制自动提醒及其提示音。发送真实测试通知，可请求浏览器授权并检查投递。

<a id="use-this-package"></a>
## 使用本包

在提供设置、语言、插槽和会话服务的 Web 客户端组合中，挂载偏好所有者和本页面：

```yaml
- name: '@deepseek-ai/dsh-notifications'
- name: '@deepseek-ai/dsh-client-ui-notifications'
```

页面按行组织桌面通知、免打扰时段和声音，提供全局启用、完成提醒、工具结果响铃、专注静默、每日免打扰时段、声音选择、自定义音频和测试操作。[通知 schema](../../notifications/notifications/src/settings.ts) 拥有持久字段和默认值；仅单独挂载的通知插件登记它，重载页面不能重新创建已卸载的命名空间；启用偏好不会授予浏览器通知权限。

编辑使用 `notifications` 命名空间。加载中、不可用和只读设置会禁用编辑。写入被拒绝时，页面恢复已接受的主机值，并提供显式重试。恢复默认会原子移除全部通知覆盖项，包括等于继承值的覆盖及免打扰时段，使主机重新解析默认值。

定时免打扰默认关闭，时段为 `22:00`–`08:00`。它采用浏览器当前的本地时间，包含开始时刻，不包含结束时刻。时段可以跨午夜；起止时间相同表示全天静默。被抑制的提醒和声音会丢弃，不会补发。编辑两个时间后选择**保存免打扰时段**，即可一次提交；草稿保留开始编辑时的版本，显式重试使用恢复后的主机版本。

测试操作绕过专注静默和定时免打扰，遵循全局启用，并在需要时请求浏览器授权。后台事件要求权限已获授予。投递失败不会改变偏好，页面会提示检查通知支持和权限。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

[客户端插件](src/client/index.ts) 在同一 slot 声明生命周期内注册个人偏好分区及本地化搜索项。渲染器将设置源绑定为 hook，组件接收显式命令。搜索只索引公开标签、说明和关键词，不索引设置值或自定义文件名。每一项都有始终挂载的导航锚点。

[投递运行时](src/client/runtime.ts) 在观察到 `api-session/status` 从运行转为空闲时发送完成提醒，并在连接重置时清除该观察状态。新追加的 `tool/result` 含有 BEL（`\u0007`）时发送响铃提醒；替换历史和历史翻页不会触发提醒。投递读取当前启用、焦点、本地免打扰时段和声音偏好，并在异步权限处理后重新检查。插件释放时移除监听器并撤销自定义音频 URL。

覆盖项有变更时，[偏好命令](src/client/settings-actions.ts) 要求主机接受写入，且有效值和显式用户覆盖与选择一致。已存在且匹配的覆盖项无需写入；重新选择相同自定义文件名会将新音频字节附加到当前浏览器运行时。重置确认所属覆盖项已移除。共享设置 scope 拥有串行写入、版本校验和冲突恢复。被拒绝的写入仍报告失败，即使恢复读取发现其他写入方已提交相同值。

本包不发布运行时不变量伴随插件：它消费设置和会话所有者的快照，不拥有独立复制的业务状态。

</details>

<a id="model-experience"></a>
## 模型体验

无，因为通知控件与投递不改变模型请求、工具或会话记录。

#### KV Cache 影响

无。通知偏好不进入模型输入或 KV cache。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

通知投递依赖当前浏览器及其已获授予的系统权限。

- 自定义音频字节只在当前页面运行时有效，仅文件名会持久化。重新加载后需重新选择文件，浏览器自动播放策略也可能阻止声音播放。
- 终端响铃提醒消费新工具结果中的 BEL，不消费原始交互终端流。完成表示观察到从运行转为空闲，不能区分成功完成、取消或失败。
- 免打扰时段跟随当前浏览器的时钟和时区，也遵循本地夏令时变化。不同设备可能在不同时间进入同一时段。页面不提供音量和独立的声音启用偏好。
- 浏览器通知支持和操作系统策略决定通知投递及系统默认声音。测试成功仅确认浏览器接受了通知，不能确认操作系统是否已显示通知或播放声音。
