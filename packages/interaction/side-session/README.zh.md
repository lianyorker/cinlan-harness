# @deepseek-ai/dsh-side-session

[English](README.md) | 中文

## 概要

交互式侧会话与合并回写机制：纯帮助函数，从父会话事件日志推导连续且闭合的种子前缀，并描述侧会话结果如何合并回父会话。

## 使用本包

打开交互式侧会话的消费者（例如评审或聚焦子任务）用父会话完整事件日志调用前缀帮助函数。未闭合的 turn 与尾随的步骤活动被排除，返回的种子停在已闭合的完整 turn 边界；侧会话从该闭合状态开始，合并回写把其结果重放进父会话。

## 模型体验

无：本包只为消费者计算事件日志边界，不注册提示词、工具或 Session 内容。

#### KV Cache 影响

无直接影响；派生种子的模型侧用途由会话消费者持有。

## 已知限制与延期工作

- 种子严格连续：父会话存在未闭合 turn 时截断在最后一个已完成 turn，进行中的工作不会被继承。
- 合并回写只是机制帮助函数，不是授权边界；调用方保留自己的审批流程。
