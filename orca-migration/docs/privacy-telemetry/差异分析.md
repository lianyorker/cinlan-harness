# 隐私、Telemetry 与诊断同意

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 隐私开关 | Privacy pane 将 usage data/telemetry 设为用户偏好 | OTel 与 Client analytics 由 settings 命名空间及 Session log 开关精细化控制，桌面端按需装配；Web 端默认不挂载 | `设计不同` |
| 支持包 | 诊断收集、预览、上传与删除单独操作 | 产品统计不能代表用户主动上传支持包 | `设计不同` |
