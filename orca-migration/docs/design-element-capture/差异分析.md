# Design Mode 与元素捕获

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 点选与捕获 | README 描述 Chromium 点选元素，将 HTML/CSS/裁剪截图加入 prompt；具体采集 handler 未在本次片段完整追到 | browser_select_element/browser_capture_element 实现 selection/observation 校验与 image attachment | `设计不同` |
| 模型输入 | Design Mode 是用户点选的 prompt 工作流 | 工具捕获需 image-capable route，并可 deferContext；并非相同 UI 发起方式 | `设计不同` |
