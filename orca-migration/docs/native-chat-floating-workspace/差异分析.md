# Native Chat 与浮动工作区

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 面板内容 | 浮动工作区与 terminal/native-chat 等体验 | 同一会话 Chat 的浮动和 docked 形态；不是完整 terminal/browser 工作区 | `设计不同` |
| 入口与焦点 | 浮动面板/窗口、最大化与焦点 | header utility、shell overlay、右侧栏 tab 和 keyboard command | `部分实现` |

## 迁移范围
