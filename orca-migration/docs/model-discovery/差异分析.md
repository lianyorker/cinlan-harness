# 运行时模型发现

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 端点探测与候选采纳 | Claude/Codex/ACP 使用与会话相同的 binary/env resolver | remote.llm.discoverModels 提供统一端点探测，ModelListEditor 提供动态候选过滤弹窗、增量采纳与上下文/Token/模态推导 | `设计不同` |
| 配置与就绪联动 | 账号/环境配置参与选择默认项 | Models store 与 settings/credentials/remote 实时联动，支持就绪徽标、未就绪引导与会话上下文绑定 | `一致` |
