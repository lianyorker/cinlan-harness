# 仓库 Setup/Cleanup Hooks

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 脚本来源策略 | repo/local/both 命令来源与 setup run policy | 显式 WorktreeTaskHook executable/args，非同名脚本发现策略，杜绝仓库代码无确认静默执行本机命令 | `设计不同` |
| 失败恢复 | Setup/Cleanup 配置进入仓库 pane | resolveHook/runHook、超时与溢出拦截、cleanup receipt 留存与重试逻辑完备；前端设置表单支持独立编辑与重置 | `一致` |
