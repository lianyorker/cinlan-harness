# 自动化与 Schedule

## 结论

源码级结论：`设计不同`；建议优先级：`P0`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 任务编辑 | 独立 Automation 页面、编辑器和运行目标 | Schedule 将到期任务作为原 Session 的 follow-up | `设计不同` |
| 运行记录 | Automation runs 与运行详情 | Session task cards/任务目录，不等价于独立 Automation run-history | `部分实现` |
