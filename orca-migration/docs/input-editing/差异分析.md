# 输入与剪贴板行为

## 结论

源码级结论：`设计不同`；建议优先级：`P2`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| Primary selection | InputPane 的 middle-click paste 与 platform default | 输入触发体系由 ui-input-trigger 统一承载，支持 @ 引用触发、菜单定位与键盘/鼠标协同；剪贴板与原生操作沿用宿主平台事件默认流 | `设计不同` |
| 剪贴板与终端 | terminal interaction/OSC52 等设置 | 终端交互由 ui-settings-terminal 统一管理字体、光标、回滚与选择复制偏好，与聊天输入框保持分权解耦 | `设计不同` |
