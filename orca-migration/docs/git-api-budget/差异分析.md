# Git Provider API 预算

## 结论

源码级结论：`一致`；建议优先级：`P2`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 预算显示 | GitHub/GitLab rate-limit panel | 设置页 Integrations 卡片展示 provider 连接状态、账号与请求配额剩余/上限 | `一致` |
| 额度恢复 | 按 provider 显示 API budget | 按 provider 探测 rate_limit，精确解析重置时间戳（RFC 3339 本地格式化），支持全局刷新重试 | `一致` |
