# 浏览器偏好、Profile 与 Cookie

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 个人偏好 | 主页、搜索引擎、缩放、UserAgent 与链接修饰键 | sidebar navigation/Chat linkOpening，Browser preferences 由 profile 与 Cordis volatile 配置统一管理 | `设计不同` |
| Profile 与 Cookie | 按 Host 选择 default/non-default profile，导入 cookie，client-hosted/SSH routing | Playwright provider 支持多 profile 隔离存储、cookie 导入校验与 CDP attach 路由 | `设计不同` |
