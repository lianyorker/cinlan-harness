# 交付物与会话历史

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 交付物呈现与交互 | Artifacts 独立页面与发布配置 | ui-deliverables 将交付物贴近 Agent turn 过程与工具产出，提供变更文件比较浮层、卡片详情与原生打开 Review 标签页联动 | `设计不同` |
| 会话归档与日志管理 | SessionHistory 设置包含外部会话历史配置 | ui-settings-unarchive-sessions 支持已归档会话检索与恢复，ui-settings-session-log 支持会话日志导出与合规脱敏 | `一致` |
