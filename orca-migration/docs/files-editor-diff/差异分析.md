# 文件编辑与 Diff Review

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 文件与预览 | Monaco 多文件编辑器与实时 autosave | 工作区树状浏览、多 tab 高保真文档预览（Markdown/Excel/PDF/Office/Code）与外部 IDE 唤起 | `设计不同` |
| Diff 审查与行评论 | DiffViewer 与行内 Review 体验 | 右侧栏 ReviewBody 统一 Diff 解析、行级变更对齐、行评论编辑草稿与 Agent 上下文回传 | `一致` |
