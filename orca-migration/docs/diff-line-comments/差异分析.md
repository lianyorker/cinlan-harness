# Diff 行评论与发送 Agent

## 结论

源码级结论：`一致`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 行定位与编辑 | DiffViewer 提供行定位、onAddLineComment 和内联评论装饰器 | ReviewBody 提供统一 Diff 解析、old/new 行号双栏对齐、行级 + 评论触发、草稿维护与增删操作 | `一致` |
| 发回 Agent | README 描述将 diff line comments 结构化发回 agent | ReviewBody 定义 DiffLineComment 结构，支持单条及全部发送，联动 remote.session.prompt 发回 Agent 上下文 | `一致` |
