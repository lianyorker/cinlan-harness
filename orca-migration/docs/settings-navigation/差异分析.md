# 设置导航与搜索

## 结论

源码级结论：`设计不同`；建议优先级：`P0`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 入口与分组 | 导航由 metadata builder 与 hooks 构建，含八个通用组和项目条目 | settings.section ledger；SettingsGroupId 含 capabilities 等八个允许值，并非每组都一定显示 | `设计不同` |
| 搜索定位 | section/subsection 搜索、排名、能力安装状态和延迟挂载 | settingsMetadata 注册标题、关键词和 anchor；壳读取动态 ledger | `部分实现` |
