# 集成终端与 Shell

## 结论

源码级结论：`一致`；建议优先级：`P0`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| Tab 与恢复 | terminal pane 的 split/tab、运行态和恢复 UI | 右侧栏多 terminal tab、Dockkit 浮动/停靠与 Host controller 生命周期管理；支持独立会话恢复、退出码展示与关闭确认，LLM turn 取消不误杀独立终端 | `一致` |
| 渲染和 Shell 设置 | WebGL、字体、光标、Windows/WSL shell、setup script | 独立终端设置页（Shell、参数、字体、字号、Scrollback、光标样式与闪烁）；自动适配主题配色与终端容器尺寸，快捷命令菜单与快速启动集成 | `一致` |
