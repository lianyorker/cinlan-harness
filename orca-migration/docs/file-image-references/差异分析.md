# 文件引用、拖放与图片附件

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 引用菜单 | NativeChatComposer 使用 @file/slash hooks 与 agent-aware 文件引用 | 统一 @file/@session 候选、目录 drill、引用 chip 与可取消查询（ui-reference + ui-input-trigger，165 项单测） | `设计不同` |
| 拖放和图片 | composer 的 file-drop/attachment hook 与 README 拖文件/图片能力 | DropOverlay 拖放浮层、ComposerAttachments 托盘、file-upload 流式上传、模型视觉限额与多图历史渲染（ui-attachment + file-upload + ui-conversation，713 项单测） | `一致` |
