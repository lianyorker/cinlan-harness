1. 子系统差异分析：对比 Orca 在该子系统的设计理念，与 Harness 现有机制的区别。明确指出哪些概念需要“翻译”（例如：Orca 的 process.kill 如何映射到 Harness 的 AbortController？）。
2. 提取契约：从 Orca 代码中提取该子系统的核心接口、数据结构和通信协议。忽略其底层实现。
3. Harness 原生实现：
    - 使用 Harness 的原生机制（如配置加载器、异步事件总线、状态机）实现该子系统。
    - 如果 Harness 缺少必要的抽象，请先设计符合 Harness 风格的接口（Interface），再提供基于内存的 Mock 实现。
    - 确保不阻塞或修改 Harness 官方原有的核心流程。
4. 渐进隔离：提供独立的测试脚本，证明该子系统模块可以在没有其他 Orca 模块的情况下独立运行。

1. 【Orca 与 Harness 子系统映射表】
