## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 账号列表与 scope | 托管账号按 agent provider 和 activeRuntimeEnvironmentId 展示 | Cinlan 账号与 DeepSeek 账号在 personal 分区展示；LLM provider/credentials 在 ai 分区由 ModelsSection 统一管理；执行主机认证由 execution 分区管理 | `设计不同` |
| 模型编辑与错误 | Agents 设置与各账号区联动 | ModelsSection 使用 remote.llm/settings/credentials/session，支持动态 provider 卡片、凭据脱敏存储与实时更新通知 | `设计不同` |
