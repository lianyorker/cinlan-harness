# 移动设备与模拟器

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 设备配置 | SDK、设备选择、availability 和模拟器 pane | Mobile Resources 与 Preferences 集成于 ui-settings-security，支持平台工具下载校验与 ADB 设备发现 | `设计不同` |
| 控制入口 | 模拟器画面与 Agent 控制 | tool-mobile-device 提供标准模型工具（observe、tap、input、keyevent 等），CompanionPanel 支持配对连接与配额保护 | `设计不同` |
