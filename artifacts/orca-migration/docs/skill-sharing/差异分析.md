# Skill 审核与链接分享

## 结论

源码级结论：`设计不同`；建议优先级：`P2`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 审核发布 | 手动预览/审核后发布 unlisted skill link，需认证 | 私有/自托管环境无官方云端发布后端；UI 明确标示不可用并引导离线 .tar.gz 归档分发 | `设计不同` |
| Agent 发布 | agent 发布能力独立开关与授权 | 设置页默认锁定并禁用 Agent 自动发布，防止未经授权与未脱敏导出 | `一致` |
