# SSH 与远程执行主机

## 结论

源码级结论：`一致`；建议优先级：`P0`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 目标表单 | SSH target、连接状态与远程 runtime | 目标表单支持 label、destination、username、port、identityFile 以及高级配置（proxyCommand、jumpHost、连接复用、连接超时），支持 ~/.ssh/config 一键导入、连通性探测、状态机与 Ephemeral VMs 配额配方联动 | `一致` |
| Host 路由 | 仓库、文件、Git、终端和浏览器各自绑定执行 Host | execution binding/runtime 已打通底层能力与路由，支持不可变 generation 部署、SFTP 校验、并发隔离与断线恢复处理，测试全绿 | `一致` |
