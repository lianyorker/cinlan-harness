# 快捷键与终端优先策略

## 结论

源码级结论：`一致`；建议优先级：`P0`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 编辑与冲突 | shortcut rows 与捕获/恢复配置 | 快捷键编辑器、命令注册、冲突高亮检测及重置/单项恢复配置体验完整对接 | `一致` |
| 终端与持久化 | orca-first/terminal-first 策略 | durable keybindings 持久化、terminal/editable/page scope 分级拦截及 Linux/Windows 终端保护策略对齐 | `一致` |
