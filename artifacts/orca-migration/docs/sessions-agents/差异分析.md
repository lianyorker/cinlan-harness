源码级结论：`设计不同`；建议优先级：`P0`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 状态与运行面板 | 外部 agent runtime、Dashboard/Kanban、终端关联 | Session/turn/step、LLM stream 与工具事件投影 | `设计不同` |
