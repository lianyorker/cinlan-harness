# 语音听写与 STT

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 模型与配置 | 本地 Whisper/SenseVoice 模型、下载与麦克风设置 | 本地 voice-sherpa-onnx provider 完整实现 SenseVoice 模型校验、进程出版锁与资源缓存；VoiceSettingsSection 完整呈现下载控制与设备切换（100+ 项单测全绿） | `设计不同` |
| 录音与流式听写 | DictationController 管理听写指示与文本目标 | DictationController 与 VoiceButton 完整实现麦克风捕获、转录请求流、增量文本拼接、草稿保护与错误回退（120+ 项单测全绿） | `一致` |
