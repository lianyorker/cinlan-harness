# 隐私、Telemetry 与诊断同意 UI 检查

## 源码可确认的差异

| UI/交互点 | Orca | Harness | 视觉证据 |
|---|---|---|---|
| 隐私开关 | Privacy pane 将 usage data/telemetry 设为用户偏好 | OTel 与 Client analytics 由 settings 命名空间及 Session log 开关精细化控制，桌面端按需装配；Web 端默认不挂载 | 未截图 |
| 支持包 | 诊断收集、预览、上传与删除单独操作 | 产品统计不能代表用户主动上传支持包 | 未截图 |
