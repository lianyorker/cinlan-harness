# Relay、配对与 E2EE

## 结论

源码级结论：`设计不同`；建议优先级：`P0`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 部署与路由 | Orca relay/pairing/runtime RPC | 独立 Director/Cell 与 self-host relay，职责不能直接等同 SessionManager | `设计不同` |
| 加密与设备 | 版本化 E2EE framing 和 phone protocol | 自有 wire protocol/crypto，需要明确兼容性目标，不能自动视为互通 | `设计不同` |
