# 远程 Runtime 与临时 VM

## 结论

源码级结论：`一致`；建议优先级：`P2`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 远程服务器 | 保存/配对 Remote Orca Server，与裸 SSH 分开 | 通过 execution host targets 与 execution-runtime 协同提供远程主机与运行时管理 | `一致` |
| VM 配方 | EphemeralVmsPane 查询 recipe catalog 和技能安装状态 | EphemeralVmsSection 完整展示已核准配方（Debian/Security/Worker）、实时配额利用、启动参数表单与终止确认 | `一致` |
