JSON 无效、远程离线、stdio/HTTP、凭据缺失、保存冲突、probe 失败、删除确认、重连 generation 和 teardown。

截图与操作收据使用 `artifacts/orca-migration/exports/ui/mcp-servers/`；记录 profile、版本、viewport、动作、结果和错误。Orca Electron 仅在明确授权启动后按上游隐藏窗口/CDP 规则验证，不抢用户焦点。
