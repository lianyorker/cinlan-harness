# 浏览器与电脑操控

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 页面与导航 | Browser pane 配合 Host routing/profile | ui-sidebar-browser 支持 ElectronWebViewImpl 与 IframeImpl 双端渲染，导航控制器、历史栈与生命周期全量解耦 | `设计不同` |
| 自动操控与权限 | Browser Use 与 Computer Use 设置分开 | tool-browser 与 tool-computer-use 分别拥有独立权限策略（browser/computer permission policy），会话事件可回放 | `设计不同` |
