## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 任务来源 | TasksPane 明确包含 GitHub、GitLab、Linear、Jira | WorkItemsSection 提供 github/gitlab/linear 工作项关联、会话链接与写面板（两阶段确认） | `设计不同` |
| Review 展示 | Git 设置和任务/Review 工作流 | ui-work-items 与 ui-git-settings 独立解耦，差异与交付物通过 ui-deliverables 管理 | `设计不同` |
