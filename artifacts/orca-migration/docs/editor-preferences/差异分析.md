# 编辑器偏好与保存策略

## 结论

源码级结论：`一致`；建议优先级：`P2`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 编辑偏好 | Diff 视图（inline/side-by-side）、换行、空白符显示与偏好存储 | ui-right-sidebar DiffPreferencesRow 注册进 settings.general.item，ReviewBody 完整支持双模渲染与工具栏 | `一致` |
| 保存与策略 | 文件写入/变更状态与 autosave 策略 | 工作区写入由 Agent 会话任务受控管理，偏好面板明确标识受控状态，不伪造只读保存开关 | `一致` |

## 迁移范围

与 files-editor-diff 共同界定是否建设可写编辑器；autosave 必须声明时机、版本冲突和恢复，不向只读预览添加虚假的保存开关。
