# 工作区端口发现与 SSH 转发

## 结论

源码级结论：`一致`；建议优先级：`P2`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 端口列表 | 按 runtime target 扫描、可见性/防抖与 unavailable 保留语义 | ui-right-sidebar PortsBody 完整实现扫描刷新、空列表与 target unavailable 严格区分 | `一致` |
| 转发操作 | SSH ports panel 区分端口与 forwarding 状态 | 支持快速转发、手动配置、本地端口冲突检测、持久化以及断线释放与停止 | `一致` |
