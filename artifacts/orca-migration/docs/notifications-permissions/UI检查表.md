# 通知与原生权限 UI 检查

## 源码可确认的差异

| UI/交互点 | Orca | Harness | 视觉证据 |
|---|---|---|---|
| 通知设置与免打扰 | agent/terminal 事件的原生通知偏好、声音选择与静音时段 | Web/桌面双端通用的系统通知偏好、自定义声音注册与每日免打扰时段 | 未截图 |
| 原生权限与审批 | macOS developer privacy 权限检查与系统入口 | 标准 W3C Notification 权限自适应探测；工具/系统操作审批由 ui-approval 分离独立治理 | 未截图 |
