# 主题、字体与界面外观

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 主题与字号控件 | System/Dark/Light、语言与界面选项 | ui-theme 通过 settings.general.item 插槽注入 AppearanceRow（系统/明亮/暗黑）与 FontSizeRow（阶梯字号），HTML 挂载前通过 boot-theme 预设防止主题闪烁 | `设计不同` |
| 窗口与桌面偏好 | AppearanceWindowSidebarSection 混合窗口缩放、侧栏开关与应用图标 | 严格解耦 Web CSS 设计令牌与 Electron 桌面原生层，桌面窗口缩放与拖拽由 apps/desktop 原生适配管理，侧栏由 ui-sidebar 响应式折叠状态机管理 | `设计不同` |

## 迁移范围

已落地：以 ui-theme 统一管理全局主题与设计令牌（--dsw-theme-*、--dsw-radius-*），通过 settings.general.item 提供主题与字号选择，通过 boot-theme.ts 根治启动白屏闪烁，桌面原生窗口缩放由 apps/desktop 统一管理。
