## 结论

源码级结论：`设计不同`；建议优先级：`P2`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 实验开关 | agent hibernation、worktree card、pet 等偏好 | Harness 调试/creator mode 语义不同，未选择迁移全部装饰实验 | `设计不同` |
