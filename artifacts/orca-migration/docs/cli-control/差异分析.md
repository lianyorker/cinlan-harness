# CLI 控制与自动化入口

## 结论

源码级结论：`设计不同`；建议优先级：`P2`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 命令体系 | README 描述 worktree create/snapshot/click/fill；CommandSpec 有 flags/alias/destructive/identity 角色 | runCli 分发 profile/plugin/dump-config；args/help 使用 clh，模型工具经 Harness 运行 | `设计不同` |
| 桌面注册 | CliSection 检查 install status，提供注册/移除及 WSL 入口 | Desktop 有 fingerprint/receipt/rollback 管理源码；对应注册 UI 尚未证实，收据/backup/pending 仍用 .dsh-* | `部分实现` |
| 二开命令与发布身份 | Orca 是独立产品，不使用 Harness 的 CLI 命名 | apps/cli/package.json 同时注册 clh、cinlan-harness、dsh，package name 仍为 @deepseek-ai/dsh；未完成与官方命令/发布坐标隔离 | `部分实现` |
| 用户数据根目录 | Orca 路径不能直接映射为 Harness 用户根目录 | 默认 ~/.clh，CLH_HOME/CINLAN_HARNESS_HOME 优先，但仍自动回退 DSH_HOME；不能视为官方与 CLH 数据已隔离 | `部分实现` |

## 迁移范围

按用户自动化任务映射到 clh/SDK/工具，不为每个 Orca verb 新造 application bin；caller/target identity、危险动作与权限必须明示。按 CLH 隔离规则核对命令、发布坐标、用户根目录与安装收据，禁止占用官方 dsh 或隐式继承 DSH_HOME；保留命令 fingerprint、changed-entry 拒绝与回滚，安装注册属于独立桌面部署动作。
