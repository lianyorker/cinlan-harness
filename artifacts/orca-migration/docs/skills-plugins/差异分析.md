# Skill 与插件管理

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| Skill 展示与调用 | SkillsPage、来源与安装/更新体验 | packages/skill/skill 多层优先级分层加载（bundled/project/user/runtime）与调用策略（modelInvocable/userInvocable），配合 ui-skill 会话展示与分享（124 项单测全绿） | `设计不同` |
| 插件管理与生命周期 | Orca plugin catalog、权限与开发路径 | ui-plugin-manager 独立大页与 ui-settings-plugins，实现插件动态安装、配置台账、热重载通知与持久化（196 项单测全绿） | `设计不同` |
