# 终端快捷命令

## 结论

源码级结论：`一致`；建议优先级：`P2`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 命令编辑 | 按执行 Host 编辑，scope selection 与刷新错误 | 设置页独立快捷命令目录，支持按 Host 隔离增删改查及保存校验 | `一致` |
| 执行与删除 | 命令菜单、编辑器、删除确认与 Host current 检查 | 终端连接后动态提供快捷命令菜单、一键确认运行、删除确认保护 | `一致` |
