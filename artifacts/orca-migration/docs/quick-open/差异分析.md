# Quick Open 与命令检索

## 结论

源码级结论：`设计不同`；建议优先级：`P1`。结论限于 2026-10-10 固定基线，不是运行或视觉验收通过。

## 功能与 UI 差异

| 对比点 | Orca 已有设计 | 当前 Harness | 判断 |
|---|---|---|---|
| 文件检索与引用 | QuickOpen 模态弹窗按 worktree 搜索文件 | Composer 内联 @ 触发器（ui-reference + ui-input-trigger，165 项单测）支持递归目录穿透与原子引用，配合侧栏文件树快速定位（82 项单测） | `设计不同` |
| 命令检索与调度 | QuickOpen 弹窗搜索与执行命令 | Composer 内联 / 斜杠指令与 PopupSelect 弹窗（ui-commands，143 项单测），配合 ui-shortcuts 键盘优先快捷键体系（309 项单测） | `设计不同` |

## 迁移范围

已落地：以会话为中心，通过 ui-input-trigger 统一调度 @ 引用（ui-reference）与 / 指令（ui-commands），结合侧栏文件树与全局快捷键体系，提供上下文保留的检索体验。
