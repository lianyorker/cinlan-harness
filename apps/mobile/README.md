# Cinlan Mobile App (移动端)

Cinlan 是一款面向远程控制、智能体管理及终端协作的移动端套件。本项目由原 Orca 进行二次品牌定制与中文化开发。

## 项目结构与页面路由

```text
apps/mobile/
├── src/
│   ├── assets/              # 图标、品牌 Logo (Cinlan)
│   ├── components/          # 公共组件 (Card, Button, Modal, etc.)
│   ├── screens/
│   │   ├── ConnectDesktop/  # 1. 引导/扫码连接页
│   │   ├── Settings/        # 2. 设置中心
│   │   ├── ManualPair/      # 3. 粘贴配对码界面/弹窗
│   │   ├── Notifications/   # 4. 通知配置引导
│   │   └── Dashboard/       # 5. 欢迎首页 (工作台)
│   ├── locales/
│   │   └── zh-CN.json       # 中文文案词条
│   └── navigation/          # 路由配置文件
└── README.md
```

## 设计规范与色彩体系

- **设计风格**：深色工业/极客极简风（Dark Minimalist）
- **核心色彩**：
    - 背景色：`#0A0A0A` / `#121212`
    - 卡片/模块背景：`#18181A`
    - 描边/分割线：`#27272A`
    - 主文字色：`#FFFFFF`
    - 次级辅助文字：`#8E8E93` / `#A1A1AA`
    - 品牌高亮/主按钮：`#FFFFFF` (背景) + `#000000` (文本) 或 `#22C55E` (在线状态指示灯)

## 各页面原型与文案字典 (提示词)

### Page 1: 首次配对引导 (开屏/配对主页)

* **路由**：`apps/mobile/src/screens/ConnectDesktop`
* **功能**：未检测到关联桌面客户端时的初始展示，引导用户打开桌面端并扫码配对。

#### UI 元素与布局

- **顶部栏**：左侧品牌 Logo + `Cinlan`，右侧齿轮设置图标（点击跳转设置页）。
- **中心主视觉区**：
    - 主标题：`连接您的电脑`
    - 说明文案：`在电脑上与 Cinlan 配对，以查看您的智能体、进入任何终端，并直接通过手机推进工作。`
    - 主行动按钮（Primary Button）：`[ ⛶ ] 配对电脑`
- **底部指引流程 (工作原理)**：
    - 栏目名：`工作原理`
    - 步骤 1：
        - 序号：`1`
        - 标题：`打开 Cinlan 电脑端`
        - 描述：`前往“设置 -> 移动端”并生成配对二维码。`
    - 步骤 2：
        - 序号：`2`
        - 标题：`扫描二维码`
        - 描述：`点击上方按钮打开相机，对准屏幕上的二维码。`
    - 步骤 3：
        - 序号：`3`
        - 标题：`已连接`
        - 描述：`您的电脑将显示在此处。一切都经过端到端加密。`

---

### Page 2: 系统设置 (Settings)

* **路由**：`apps/mobile/src/screens/Settings`
* **功能**：全局应用参数配置、网络会话行为定制以及帮助支持。

#### UI 元素与布局

- **顶部栏**：返回箭头 `<` + 标题 `设置`
- **主要配置分组（列表卡片）**：
    - `>_` 终端 (Terminal)
    - `💬` 聊天界面 (Chat UI)
    - `🌐` 浏览器 (Browser)
    - `🎙️` 语音 (Voice)
    - `🔔` 通知 (Notifications)
    - `🔧` 故障排除 (Troubleshooting)
    - `ℹ️` 关于 Cinlan (About)
- **协议与支持分组**：
    - `🛡️` 隐私政策 (Privacy Policy)
    - `⚙️` 支持与反馈 (Support)

---

### Page 3: 手动粘贴配对码 (连接方式回退)

* **路由**：`apps/mobile/src/screens/ManualPair`
* **功能**：当相机权限未开启、环境光线不足或无法调取扫码枪时的备选配对流程。

#### UI 元素与布局

- **顶部栏**：返回箭头 `<`
- **中心提示区**：
    - 主标题：`使用配对码连接`
    - 解释说明：`由于相机访问受限或未能扫码，您可以使用配对码。请在下方输入您在电脑端获取的配对码。`
- **交互表单卡片**：
    - 输入框占位符：`请输入或粘贴配对码 (例如: TEzNDI1ODE5...)`
    - 快捷操作按钮：`[ 📋 粘贴 ]`
- **底部行动按钮**：
    - 主按钮：`确认连接` / `保存`
    - 次按钮：`取消`

---

### Page 4: 权限与通知配置 (首次引导流)

* **路由**：`apps/mobile/src/screens/Notifications`
* **功能**：引导用户授权系统通知，确保智能体长任务执行完成或需要人工介入时能够即时推送到手机端。

#### UI 元素与布局

- **顶部栏**：品牌 Logo `Cinlan` + 分页指示器（Dots，当前位于第 2 步）
- **动态模拟通知卡片区**：
    - 通知卡片 1：
        - 来源/时间：`Cinlan · 刚刚`
        - 标题：`Codex 已完成`
        - 状态详情：`测试已通过。`
    - 通知卡片 2：
        - 来源/时间：`Cinlan · 刚刚`
        - 标题：`Claude 需要输入`
        - 状态详情：`正在等待您的操作。`
- **说明文案**：
    - 主标题：`不要错过智能体需要您的时刻`
    - 正文：`当智能体完成任务或需要您协助时，此手机将收到通知——即使您没有打开应用。`
    - 辅助说明：`在您的电脑闲置 3 分钟后，通过 Cinlan 的推送服务发送。您随时可以在设置中更改此设置。`
- **底部操作**：
    - 主按钮：`启用通知`
    - 次级文本按钮：`暂不开启`

---

### Page 5: 控制台工作台 (欢迎主页)

* **路由**：`apps/mobile/src/screens/Dashboard`
* **功能**：用户完成配对并登录后的应用核心主页。

#### UI 元素与布局

- **顶部栏**：左侧 Logo `Cinlan`，右侧齿轮 `设置` 图标。
- **欢迎栏**：`欢迎回来`
- **核心数据看板（三列卡片）**：
    - 统计项 1：`15` / `运行中智能体`
    - 统计项 2：`1天 12小时` / `智能体运行时间`
    - 统计项 3：`0` / `已创建 PR`
- **设备列表 (DESKTOPS)**：
    - 设备卡片：
        - 图标：电脑显示器
        - 设备名：`DESKTOP-3QU41U1`
        - 系统类型：`Windows`
        - 在线状态：`🟢 已连接 · 直接连接 · 局域网`
        - 分支/工作区统计：`0 个工作区`
        - 更多操作：三点按钮 `⋮`
- **任务概览 (TASKS)**：
    - 任务卡片：
        - 标题：`任务`
        - 来源图标：GitHub 图标 + 展开箭头 `>`
- **快捷操作 (QUICK ACTIONS)**：
    - 按钮 1：`[ ⛶ ] 配对新电脑`
    - 按钮 2：`[ + ] 新建工作区`
