# Agent Note: MCP 管理区分期望记录与连接观测

Status: implemented

[English](2026-09-17-managed-mcp-ownership.md) | 中文

## 问题

设置开关记录用户意图，却不能证明外部服务器已启动或停止。替换清理未确认的子实例可能重复工具命名空间，删除期望记录则可能隐藏未结束的进程。从独立设置数据库编辑组合拥有的条目，也会产生竞争所有者。若不明确约束公开数据，凭据值与不可信服务器描述可能经管理诊断泄漏。

## 决策

[管理器](../../../../packages/mcp/mcp-management/README.zh.md) 拥有真实当前 profile 的 revision 记录及由这些记录创建的程序化子实例。[桥接器](../../../../packages/mcp/mcp-client/README.zh.md) 拥有 SDK 连接、发现、工具登记与清理。外部根组合连接以只读形式显示真实条目或插件所有者。Agent 作用域连接不会变成 profile 管理记录，UI 也不声称 Loader 没有公开的 patch 层来源。

保存与启用先提交期望状态，随后激活。因此，启动失败会保留启用记录及其观测错误。移除先确认清理，随后提交删除。移除写入失败时，可以重新启动仍处于已提交启用状态的定义。重连重新解析凭据引用；刷新只在当前活动连接执行发现，从不调用模型工具。

桥接器在一条拥有明确所有者的释放路径中依次撤销贡献、清理 SDK、释放命名空间。关闭未确认时，管理器保留失败句柄并隔离命名空间，拒绝替换。期望禁用状态可以保持已提交，同时保留可见失败。即使独立失败句柄仍被保留，已释放的贡献也不再出现在公开注册表和工具运行时中。管理器不变量比较这些真实观测，而不是进程句柄是否存在。

期望记录保存凭据引用。解析值不进入公开快照、错误、托管诊断和显示的描述符。公开工具名中出现秘密时拒绝发现，而不是虚构另一个工具标识。HTTP 配置拒绝 URL 用户信息、查询参数与片段。[Controller](../../../../packages/api/mcp-controller/README.zh.md) 经现有认证通道传输已提交快照；即使生成器停在已 yield 的帧上，取消也会直接释放订阅。

[原生页面](../../../../packages/client/ui-settings-mcp/README.zh.md) 将草稿与权威快照分开，呈现真实发现的工具与所有者，仅索引本地化静态字段文案。[最初 MCP 决策](../feature/2026-07-07-mcp-client-plugin.zh.md) 继续拥有 SDK 选择、工具命名和模型工具桥接。管理复用该实现；旧决策是互补记录，继续有效。

## 考虑过的替代方案

**从设置数据库改写任意 Loader 组合。** 若真实配置归另一个插件或预设所有，记录就不能安全拥有连接。只读观察保留该所有者。

**关闭超时后删除或替换。** 超时不是外部服务器已停止的证据。隔离保留失败，并在清理未确认时防止复用命名空间。

**将保存成功视为已连接，或为托管服务器实现第二个桥接器。** 期望状态可以与外部就绪状态不同。一个桥接器使两条所有权路径保持相同的发现、执行和拆除语义。

## 后果

管理覆盖当前 profile 的根连接，并保留已配置的超时和重试值，不把每个选项都做成设置控件。支持静态环境变量与请求头凭据引用；OAuth、Resources、Prompts 和逐 Agent 分配控件不在本实现范围内。完整配置与失败行为归各包 README 所有。

真实 Loader 组合覆盖 revision 冲突、发现、已提交启用、清理拒绝、写入失败回滚及经过认证的 Controller 调用。关闭失败回归验证禁用且隔离的子实例在注册表中为空、工具贡献已消失，随后派发真实不变量检查；负向对照仍拒绝禁用记录对应的健康活动登记。流测试覆盖等待及暂停时的取消。运行时将桥接器、注册表和不变量入口一起打包并发布共享 chunk，使产物验证可以检查其标识一致性。
