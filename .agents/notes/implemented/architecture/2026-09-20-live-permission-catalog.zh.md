# Agent Note: 实时权限目录

Status: implemented

[English](2026-09-20-live-permission-catalog.md) | 中文

## 问题

已有会话可能跨越 Auto 审查器的安装与移除。仅存放在 Session 权限投影中的目录，无法在进程能力改变且没有新权限事件时通知选择器。

## 决策

权限服务通过生成的 Typert Remote 发布进程目录，并在 Auto 注册与卸载时发送失效通知。Session 投影只承载当前选择。浏览器先订阅再读取，拒绝过时的连接代际，并清除失败的快照。目录变化关闭权限命令选择器及待确认状态，同时保留草稿。输入框保留本地化控件，并读取同一目录。稳定的命令定义标识防止权限专用 UI 作用于覆盖同名的其他命令。

本决策部分取代 [Auto 审查记录](../feature/2026-08-28-auto-review.zh.md)中的合并投影与重启 profile 选择。该记录继续负责模型授权、取消、恢复和委派。目录不改变执行策略或 Session 序号；规范的沙箱和审批 setter 仍是写入路径。

## 考虑过的替代方案

**保留合并投影并重启 profile。** 这会限制插件能力的实时变化，并使已有选择器保留过时选项。进程目录独立于持久化会话事实管理能力可用性。

**目录变化时追加权限事件。** 能力发现属于进程状态。记录这些变化会在没有修改所选策略时制造会话历史。

## 影响

Remote 组合与两个选择器必须共享目录服务。测试覆盖注册和卸载不写入 Session、已有会话选项刷新、失败与过时读取、命令覆盖及选择器失效。UI 保留风险确认；运行时准入与沙箱检查保持独立。
