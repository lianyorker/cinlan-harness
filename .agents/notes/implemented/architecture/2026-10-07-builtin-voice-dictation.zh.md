# Agent Note: 使用 Host 自有语音模型的内置听写

Status: implemented

[English](2026-10-07-builtin-voice-dictation.md) | 中文

## 问题

GUI 语音设置与可选实验性录音控件提供独立的模型准备和偏好流程。同时组合两者会产生重复麦克风控件，用户难以确认当前识别器。

## 决策

GUI profile 将语音服务、本地 sherpa-onnx Provider、带认证的 Remote 与听写 UI 组合为内置能力。设置拥有麦克风与识别偏好；模型菜单包含选择与资源操作。本地目录使用 Orca 固定版本的 ONNX 模型。下载仍需显式发起，发布前校验确切字节数与 SHA-256。仅就绪模型可选。

实验性语音 Bundle 从官方目录退休，并在加载时从 profile 已选 Bundle 中移除。已安装的包与缓存保持不变。保留的源码与 Provider 语义由[实验性语音决策](2026-09-16-experimental-voice-input.zh.md)记录；随包 GUI 听写使用[语音子系统](../../../../docs/subsystems/voice.zh.md)。

## 考虑的替代方案

**保留实验性语音作为第二个可选控件。** 这能保留其独立准备流程，但会在同一 GUI 中留下两个录音控件和两套偏好存储。

**删除或静默导入实验性缓存。** 这能减少表面重复，但可能丢失数据，或把不兼容的清单与设置视为已校验的内置模型。退休机制保留文件；[升级指南](../../../../docs/upgrade-guide/v0.2.1-alpha.1/builtin-voice/guide.zh.md)定义显式替换路径。

## 影响与验证

GUI 只有一个听写入口，安装包携带原生运行时。模型下载、麦克风权限与录音仍需用户操作。本地处理指所连接的 Host，可能是远程主机。不导入 Orca 的云端识别器，单独转写不会启动模型轮次。

验证覆盖目录固定版本、离线和流式识别器路由、经过校验的资源发布、退休机制、浏览器偏好迁移、菜单交互，以及只写草稿的听写和之后的 Session 回放。真实模型识别准确率与打包桌面端麦克风行为仍需单独进行平台验收。
