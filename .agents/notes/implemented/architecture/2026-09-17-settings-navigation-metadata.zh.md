# Agent Note: 功能所有者登记设置导航元数据

Status: implemented

[English](2026-09-17-settings-navigation-metadata.md) | 中文

## Problem

由独立插件组成的设置外壳需要产品分组和字段搜索，同时不能了解每个功能的配置，也不能把未挂载能力当成可用页面。通用 slot 标签只能标识页面，不能定位标签页中的字段。索引解析后的设置值还可能暴露凭据或用户私有内容。

## Decision

Client 设置底座拥有随 fiber 释放的元数据服务。页面注册方提供分组归属；字段注册方提供本地化公开文案、关键词别名和稳定锚点。外壳只将描述符关联到已挂载的分区 slot，页面标签、顺序和图标仍由原 slot 账本持有。未分类的第三方分区归入扩展管理。元数据无权挂载 UI、持久化配置或启用工具。

元数据登记与对应 slot 共享 effect 生命周期。快照在无变化时保持标识稳定，语言字典变化时刷新，释放时只移除对应注册方的贡献。字段 id 和锚点在同一分区内唯一，跨标签页也不例外。搜索目标作为纯数据 owner props 传递，功能选择标签页，外壳聚焦已渲染锚点。导航状态留在 Client，不写入 Session 记录。

[slot 组成决策](2026-07-22-slot-type-chain-implementation.zh.md) 继续管理登记与渲染。本决策增加设置域持有的信息，不取代 slot 决策或 Host 持久设置的解析方式。

## Alternatives considered

将任意 group/search 字段加入通用 slot options，会让所有 UI 域承担设置专用要求。中央页面 id 表会让外壳拥有第三方功能策略，且无法跟随功能释放。从 Host schema 生成索引会纳入没有可见控件的字段，并遗漏浏览器本地设置。采用登记服务需要少量所有者声明，但保留了功能生命周期与文案归属。

## Consequences

所有者与控件共同维护锚点，并随 slot 移除描述符。已挂载页面可以解释运行能力不可用；其禁用行与详情锚点仍可搜索，定位不会触发安装、检测、授权请求或执行。外壳可以增加分组和字段导航，无需导入功能 UI 或修改 Host 设置 schema。没有字段描述符的页面仍可按页面标签搜索；未挂载分区 slot 不贡献页面。运行可用性归功能自身，不需要新增外壳路由表。

## Verification

元数据测试覆盖冲突、延迟登记、语言和字典变化、标签页目标、订阅者隔离与卸载。外壳测试仅关联已挂载 slot，对公开字段文案排序，在搜索时保留导航并聚焦选中控件。浏览器覆盖组合后的中英文页面、真实主题控件、标签页路由与移动抽屉行为。原有持久化路径继续由对应功能测试验证。
