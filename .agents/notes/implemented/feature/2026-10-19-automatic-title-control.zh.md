# Agent Note: 实时自动标题准入

Status: implemented

[English](2026-10-19-automatic-title-control.md) | 中文

## Problem

自动模型标题会增加请求，并可能在用户工作时替换已生成名称。停用整个提供者会移除显式重新生成功能，并迫使与用户偏好无关的配置重新加载。

## Decision

[标题服务](../../../../packages/session/session-title/README.zh.md)拥有默认启用的实时字段 `automaticEnabled`。关闭准入会移除待处理的自动修订，并中止在途自动调用。接受结果前再次检查该字段，晚到结果不能提交。显式刷新独立，确定性回退仍可用，用户手动命名保持固定。重新启用后接纳后续消息，不回放错过的自动工作。不改变 Session 事件或持久格式。

通用设置控件使用既有带版本检查的配置表单和已接受的 Host 值，仅在标题命名空间可用时存在，服务不生成重复页面。加载和只读连接不能修改该设置。

## Alternatives considered

停用提供者也会停用显式重新生成。只隐藏 UI 会让模型请求继续运行。取消所有标题工作会丢弃用户有意发起的刷新。新增 Session 偏好会重复表达部署级配置选择。

## Consequences

该字段影响此 Host 的所有 Session，不是单个 Session。Loader 测试覆盖待处理和在途取消、晚到结果、显式刷新、重新启用与手动命名。真实 profile 编辑器测试验证文件持久化和冷启动；客户端测试覆盖已接受值回读、拒绝、重试、只读状态、命名空间撤回和语言自有文案。不据此认定真实模型或浏览器视觉验收通过。
