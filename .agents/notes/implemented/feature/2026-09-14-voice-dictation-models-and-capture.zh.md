# Agent Note: 固定语音资源与 Host 拥有的模型任务

Status: implemented

[English](2026-09-14-voice-dictation-models-and-capture.md) | 中文

## Problem

模型目录可能在传输中断后残留、损坏后仍保留就绪标记，或属于旧目录修订。破坏性替换会在新模型失败时丢失可工作的识别器。共享缓存的多个 Host 需要持久发布决策，且不能删除其他进程仍在读取的文件。设置请求的传输生命周期不能表达模型安装的生命周期。

## Decision

现有 Voice 运行时、Sherpa 提供方和身份验证 Remote 拥有资源生命周期。安装请求返回带品牌的 Host 任务 ID。客户端显式取消精确任务；传输断开不影响已接纳工作。已挂载提供方为每个模型保留最近任务，并在释放时等待自身任务与识别器。任务状态属于 Host；安装身份持久保存。

版本是固定下载清单与识别器配置的 SHA-256 指纹。目录不声称上游发布版本，也不发现发布版本。文件模型使用固定提交的 `hf-mirror.com` URL，因为操作者网络无法直接访问 HuggingFace；GitHub 归档模型保留固定发布 URL。客户端来源移除 URL 凭据、查询和片段。稳定任务错误码伴随安全诊断，避免原始网络详情泄露源凭据。

下载准备私有暂存目录并验证固定传输字节。持久文件清单验证每个受管安装。发布比较持久修订，在提交锁内重命名暂存目录，并原子替换代指针。即使已不存在，删除仍发布新的墓碑修订。过期任务无法撤销其他 Host 的删除或替换。替换失败保留已安装指针。识别器租用已安装代及其记录的架构，直到释放；只有没有活跃或未知进程拥有租约时，才回收非活跃代。

旧目录属于用户数据：迁移绝不删除它们。固定文件缓存先复制并验证，再收养；归档标记与非空文件无法证明归档校验和，因此保持未验证。显式安装获取可信归档字节。删除墓碑阻止自动重新收养旧缓存。

本记录保留模型源决策，并取代[语音垂直切片](2026-08-30-local-voice-dictation-vertical-slice.zh.md) 中标记、取消与缓存生命周期的实现。该记录仍保留本地引擎与客户端所有权的理由。浏览器采集与麦克风行为由[听写客户端](../../../../packages/client/ui-voice-dictation/README.zh.md) 负责；原生资源就绪或文件已验证均不能证明麦克风输入正常。

## Capture ownership

客户端通过 `ScriptProcessorNode` 按设备采样率采集 PCM，再线性重采样至 16 kHz。它禁用回声消除、噪声抑制和自动增益控制，避免压制听写输入。选择该采集方式源于 MediaRecorder/解码路径出现近零采样的观察；操作者浏览器的 ScriptProcessorNode 也曾产生近零采样，因此仅切换 API 不能证明麦克风正确。AudioWorklet 迁移仍属于客户端。模型选择器向上展开，避免移动设置内容。这些客户端选择不改变 Host 资源所有权。

## Alternatives considered

**下载前删除。** 拒绝，因为临时下载或完整性故障会摧毁可用安装。不可变替换在发布前保留旧代。

**信任就绪标记或收养任意非空文件。** 拒绝，因为二者均不能证明内容完整性或目录来源。旧归档数据仍留给用户，但可信替代安装存在前不可用于识别。

**随请求取消或仅按模型 ID 取消。** 拒绝，因为断开会中止共享工作，过期操作也可能取消新任务。Host 范围的任务身份使取消显式且精确。

**使用进程内锁或按时间抢占旧锁。** 拒绝，因为不同 Host 共享文件，暂停的活跃写入方可能超过超时。独占文件系统锁串行化发布；竞争方绝不抢占写入方锁。修订墓碑与锁内准备遵循[安全资源存储](../../../../packages/security/security-skills/src/resource-store.ts)。

## Consequences

替换需要同时容纳两代的临时磁盘空间。未知读取方和保留的旧数据可能占用额外空间。被终止的写入方可能留下需确认后手动恢复的锁；被终止的任务可能留下暂存目录。完成和取消的任务清理传输分段，后续任务从头开始。提供方重载重置任务回执，但重新读取持久资源状态，不会困在永久拒绝的刷新链中。

所有者本地测试使用真实 Loader 组合、Remote 通道、受控 HTTP 小模型，以及真实进程验证发布和租约生命周期。组合测试仅替代原生识别。真实模型准确度、麦克风采集与已安装 Desktop 打包需要各自所有者提供独立冒烟证据。
