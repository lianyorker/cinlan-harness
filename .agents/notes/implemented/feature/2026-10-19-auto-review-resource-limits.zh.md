# Agent Note: 有界 Auto 审查请求

Status: implemented

[English](2026-10-19-auto-review-resource-limits.md) | 中文

## Problem

授权审查在工具体前运行，可能拖延调用与集成卸载。无界输入和生成还可能消耗模型容量，部署无法控制上限。

## Decision

[Auto 插件](../../../../packages/guard/auto-review/README.zh.md#review-limits)要求明确配置输入字节、输出 token 与期限。完整系统策略加已封装用户输入超限时，在请求发送前拒绝，不截断授权证据。输出 token 上限与期限信号传给模型提供方。期限到达后，在执行工具前拒绝任何晚到响应；用户取消与集成卸载保持既有优先级。提供方必须响应取消才能及时结清，卸载仍等待自己拥有的审查，不遗弃工作。

此决策仅部分替代 [Auto 决策](2026-08-28-auto-review.zh.md)中的无限制请求选择。其权威规则、完整主机权限执行、会话级显式选择与实验隔离仍然有效。不改变 Session 事件或格式；缺少持久审查输入记录的问题仍未解决。

## Alternatives considered

截断历史可能丢失撤销或范围约束。用计时器竞速后遗弃模型流，会在卸载时留下无主工作。固定插件常量会阻止部署选择自己的资源上限。

## Consequences

此前可接纳的大型或缓慢审查可能按拒绝处理。Bundle 提供明确限制，直接插件组合必须提供全部字段。所属测试覆盖 UTF-8 精确边界、多出一字节、提供方 token 转发、无效配置、计时器清理及忽略取消后晚到的放行。不据此保证永不结清的提供方能终止，也不证明真实提供方的 token 计量。
