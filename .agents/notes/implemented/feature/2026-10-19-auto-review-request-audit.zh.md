# Agent Note: 持久 Auto 审查输入

Status: implemented

[English](2026-10-19-auto-review-request-audit.md) | 中文

## Problem

Auto 审查可以授权完整主机权限的工具执行。用当前策略文本或临时 PTC 绑定元数据重建早期决定，不能确定当时精确的模型输入。

## Decision

[Auto 插件](../../../../packages/guard/auto-review/README.zh.md#request-audit)在模型请求发送前追加必需的仅记日志事件 `auto-review/request`。事件捕获精确系统策略、唯一用户文本块、路由、采样温度、输出 token 上限、期限及带作用域的原生/PTC 调用标识。输入预算拒绝不记录发送尝试，追加失败按拒绝处理。审计不进入对话表层，也不进入后续审查历史。此事件不保留提供方流、reasoning、解析风险或原始响应。

此决策部分替代 [Auto 记录](2026-08-28-auto-review.zh.md)的输入保留决策。其风险策略、权威顺序、会话级选择及生命周期仍有效。必需事件机制拒绝缺少此词表的旧读取器，更新后的读取器用既有物理编码保留事件。源码 schema 分类将其报告为新增事件，但整库确认仍被独立的已确认 V4 差异阻止；本记录不是兼容确认或稳定晋升批准。

## Alternatives considered

从当前源码重建会丢失历史策略与绑定。复用主模型 header 或标题记录会把请求归给错误所有者。将事件标为可忽略会允许不认识它的构建丢弃精确授权输入。仅保留哈希不能重建模型请求。

## Consequences

Session 日志与原始导出包含额外敏感输入，包括过滤后的用户消息、工具描述及参数；沿用存储访问控制和保留策略，不新增脱敏。所属测试检查发送前提交、原生/PTC 标识、完整请求相等、追加失败拒绝、预算拒绝、不投影主历史及严格编码/恢复/重开。实时追加不保证同步刷入文件系统。提供方是否收到、响应是否获认证及真实 API 验收不在此证据范围。
