# Auto 审查输入保留

[English](guide.md) | 中文

## 变更

当前会话选择的 Auto 模式在发送前写入必需的仅记日志事件 `auto-review/request`，包含精确系统策略与用户文本、模型路由、采样温度、输出 token 上限、期限及带作用域的调用标识。没有此事件的已有日志仍可读取。缺少该事件词表的构建会拒绝相关日志，而不丢弃输入。Session 物理编码不变，但整库持久化确认仍未解决，本变更不代表稳定晋升获批。

审查输入可能含敏感用户消息与完整工具参数，将随 Session 日志保留和导出，不脱敏；不进入主模型对话历史。请求事件不保留 reasoning、原始审查响应或解析后的风险。

## 迁移

1. 恢复本构建写入的 Auto Session 前，升级所有用于打开相关日志的 Host 或 SDK 读取器。不要删除事件或将其标为可忽略来绕过旧读取器拒绝。
2. 选择 Auto 前检查 Session 存储权限、保留策略、原始导出及备份访问。切换其他权限模式会停止后续 Auto 审查，但不擦除已有审计记录。
3. 审计仅代表记录了发送尝试，不证明提供方收到请求或已返回有效授权结果。追加失败时，审查模型与工具体均保持未执行。
