# 同步部署 Host 与手机页面产物

[English](guide.md) | 中文

## 变更

加密手机传输将超过 256 KiB 的 JSON 消息拆为经过认证的分片，完整消息上限为 16 MiB。旧手机页面不能重组这些消息。已保存的设备凭据和 Session 日志保持不变。

## 迁移

1. 同步部署配套 Host 包与重新构建的手机页面产物。
2. 通过支持的 `dsh` profile 重启 Host 后，刷新手机页面。
3. 打开此前受影响的对话，确认历史可见且连接保持已配对，无需重新配对。
