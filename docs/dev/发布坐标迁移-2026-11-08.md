## 5. 后续必备：全量重 bundle（2026-11-09 补记，实测踩实）

坐标迁移改了 `package.json.name`，而 client bundle 的 ModuleLoader id 取**构建时** package.json.name——只重编单个包会让 server 发新 rev、浏览器仍跑旧 rev bundle，表现为主界面 duplicate factory registration 幽灵症状。**发布坐标改动后合并/验收前必须跑一次全量 bundle**：

```sh
pnpm -r --if-present --no-bail --config.ignore-workspace-cycles=true bundle
```

（112 包，实测约数分钟。）排查 bundle 相关问题时先开全新隔离浏览器会话再验证，不要在旧 tab 上 navigate——旧实例的 HTTP 缓存会继续跑旧 bundle。
